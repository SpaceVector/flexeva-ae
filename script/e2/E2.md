# E2: Table 4 and Figure 5

Run E2 once on the coordinator:

```bash
script/run_e2
```

The default entry point runs Table 4 and the trace-based Figure 5 route.

## Table 4

Table 4 runs the GPT and Routed-MoE similarity cases under FakeCUDA, preserves
their raw traces, combines the eight case summaries, and validates event
coverage and weighted similarity. Its output is:

```text
result/e2/generated/table4/<run-id>/table4.csv
trace/e2/table4/<run-id>/
```

## Figure 5

The default route validates the supplied 32/64/128-GPU trace coverage,
recomputes their actual runtimes from completed step windows, checks them
against the paper-run source measurements, and regenerates every error, CSV,
and PDF. It does not start the peer or substitute a new 16-GPU run for the
larger experiments:

```bash
script/run_e2 figure5
```

Outputs are:

```text
result/e2/generated/figure5/<run-id>/trace/figure5a.csv
result/e2/generated/figure5/<run-id>/trace/figure5b.csv
plot/figure5.pdf
```

This is a limited trace-based reproduction. The source measurements cover the
paper-facing values; complete original raw traces are available only for the
linked large-scale GPT points.

To run the current-server variant, select native mode explicitly:

```bash
script/run_e2 figure5 native
```

Native mode captures GPT-8 on the coordinator, GPT-16 across both nodes, and
the five 16-GPU Routed-MoE cases. It never appends the supplied 32/64/128-GPU
points to the same CSV. Its outputs are:

```text
result/e2/generated/figure5/<run-id>/native/figure5a.csv
result/e2/generated/figure5/<run-id>/native/figure5b.csv
trace/e2/figure5/<run-id>/native/
plot/figure5-native.pdf
```

Native results describe the current socket-based reviewer environment, so the
validator records their errors without applying the paper Figure 5(a) `<4%`
criterion.

Set `TABLE4_RUN_ID` and `FIGURE5_RUN_ID` to choose identifiers. To use another
large-scale input mount:

```bash
export FIGURE5_LARGE_CLUSTER_ROOT=/path/to/figure5-large-cluster
script/run_e2 figure5
```

`FIGURE5_ESTIMATOR_MODEL` selects another independent estimator for native
mode only.

Only native mode starts the peer automatically. Do not launch a matching
command there.
