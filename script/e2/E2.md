# E2: Table 4 and Figure 5

Run E2 once on the coordinator:

```bash
script/run_e2
```

The default entry point runs both Table 4 and Figure 5.

## Table 4

Table 4 runs the GPT and Routed-MoE similarity cases under FakeCUDA, preserves
their raw traces, combines the eight case summaries, and validates event
coverage and weighted similarity. Its output is:

```text
result/e2/generated/table4/<run-id>/table4.csv
trace/e2/table4/<run-id>/
```

## Figure 5

Figure 5 captures the 8-GPU GPT point on the coordinator and the 16-GPU GPT
and Routed-MoE points across both nodes. It evaluates those fresh traces with
FlexEva and the independent estimator.

The reviewer server cannot execute the larger scale points. The artifact uses
the supplied raw traces under `large-cluster/e2/gpt-{32,64,128}` for those
three points; it does not substitute result tables or smaller runs.

Outputs are:

```text
result/e2/generated/figure5/<run-id>/figure5a.csv
result/e2/generated/figure5/<run-id>/figure5b.csv
trace/e2/figure5/<run-id>/
plot/figure5.pdf
```

Set `TABLE4_RUN_ID` and `FIGURE5_RUN_ID` to choose identifiers. To use another
large-scale trace mount or estimator:

```bash
export FIGURE5_LARGE_CLUSTER_ROOT=/path/to/figure5-large-cluster
export FIGURE5_ESTIMATOR_MODEL=/path/to/independent-estimator.json
script/run_e2
```

The distributed runner starts the peer automatically. Do not launch E2 there.
