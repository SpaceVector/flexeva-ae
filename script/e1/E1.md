# E1: Figure 1

E1 measures five successive sparse-MoE workload snapshots. The reviewer server
cannot execute the original 16-node, 128-GPU job, so the artifact supplies only
its raw traces. No Figure 1 table is stored in the repository.

The normal entry point is:

```bash
script/run_e1
```

It performs four steps:

1. validate all five supplied 128-rank trace sets and their measured-step
   windows;
2. extract rank-0 step time and NCCL send volume from those traces;
3. run each workload snapshot at logical world size 128 under FakeCUDA to
   compute dropped and rerouted token counts;
4. count the source changes between snapshots, build the Figure 1 CSV files,
   validate their arithmetic, and draw the figure.

The supplied trace root defaults to
`large-cluster/e1/historical_sparse_moe`. Use another mount with:

```bash
E1_TRACE_ROOT=/path/to/historical_sparse_moe script/run_e1
```

Each round must contain a merged `capture_manifest.json`, 128 non-empty rank
traces, and 128 non-empty marker files. The measured step window must be valid
for every rank.

The current run is written to:

```text
result/e1/generated/<run-id>/
  trace_metrics.csv
  round_*/benchmark_result.json
  trajectory.csv
  figure1b.csv
  figure1c.csv
trace/e1/<run-id>/logical-routing/
plot/figure1.pdf
```

Set `E1_RUN_ID` to choose the run identifier. Existing output is never
overwritten.
