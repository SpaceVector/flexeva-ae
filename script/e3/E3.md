# E3: Figures 6--8

Run E3 once on the coordinator:

```bash
script/run_e3
```

The default entry point runs Figures 6, 7, and 8 in order. All captures use the
two-node reviewer environment and start the peer automatically.

## Figure 6

Figure 6 captures an anchor and four candidates for GPT and Routed-MoE at 16
physical ranks. It measures full evaluation and selective refresh, builds the
cumulative timing table, validates the raw traces and timing arithmetic, and
writes:

```text
result/e3/generated/figure6/<run-id>/
trace/e3/figure6/<run-id>/
plot/figure6a.pdf
plot/figure6b.pdf
```

## Figure 7

Figure 7 runs the four production rounds with paired Maya-full and FlexEva
measurements. The driver validates every round and creates:

```text
result/e3/generated/figure7/<run-id>/
plot/figure7.pdf
```

## Figure 8

Figure 8 freshly captures the 8- and 16-GPU configurations, measures the three
evaluation paths, validates case geometry, trace completeness, refresh
accounting, and CSV consistency, then writes:

```text
result/e3/generated/figure8/<run-id>/
trace/e3/figure8/<run-id>/
plot/figure8.pdf
```

`FIGURE6_RUN_ID`, `FIGURE7_RUN_ID`, and `FIGURE8_RUN_ID` select the output
identifiers. Existing output is never overwritten.
