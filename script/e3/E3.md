# Experiment E3: evaluator efficiency and scale

E3 reproduces Figures 6--8. Figure 6 measures cumulative evaluation time,
Figure 7 breaks that time into components, and Figure 8 compares three model
and cluster scales. Submitted CSVs stay under `result/e3/`; new runs are
written below `result/e3/generated/`.

## Setup

The 16-GPU cases use two nodes with eight A100 GPUs each. Check out the same
revision on both nodes and run `script/setup` on each. FlexEva is included in
this repository under `FlexEva/`.

Set the peer connection on node 0:

```bash
export PYTHON_BIN=/path/to/node-0/python
export FLEXMAYA_MASTER_ADDR=<node-0-address>
export FLEXMAYA_PEER_TARGET=root@<node-1-address>
export FLEXMAYA_PEER_PORT=<node-1-ssh-port> # omit for port 22
export FLEXMAYA_PEER_REPO_ROOT=/path/to/node-1/new_ae
export FLEXMAYA_PEER_NODE_ROOT=/path/to/node-1/large-filesystem
export FLEXMAYA_PEER_PYTHON=/path/to/node-1/python
```

Node 0 needs non-interactive SSH access to the peer. Set `AE_NODE_ROOT` on
each server to a large local filesystem. The shared launcher has a CPU-only
check:

```bash
python3 script/lib/two_node.py self-test
```

## Figure 6: cumulative evaluation time

Each panel starts from one anchor and applies four cumulative mutations:

| Panel | Workload | Mutation sequence |
| --- | --- | --- |
| Figure 6(a) | Megatron GPT 18.4B, 16 ranks, TP2/PP8/DP1 | attention backward; +MLP backward; +optimizer; TP1/PP8/DP2 |
| Figure 6(b) | Routed-MoE, 16 ranks, EP16/DP1 | router backward; +attention backward; +optimizer; route `(0,1)` to `(7,8)` |

Maya-full uses the complete candidate process wall time. FlexEva uses the
marked changed region, except for the GPT parallel-configuration change, which
requires a full candidate capture.

Run once on node 0 with unused rendezvous and control ports:

```bash
export FLEXMAYA_MASTER_PORT=29500
export FLEXMAYA_CONTROL_PORT=29600
FIGURE6_RUN_ID=figure6-production-01 script/run_e3 figure6
```

To check the submitted ledgers without launching GPUs:

```bash
python3 script/e3/validate_results.py
python3 script/e3/plot_figure6.py
```

The run writes:

```text
trace/e3/figure6/<run-id>/{gpt,moe}/<anchor-or-round>/traces/
result/e3/generated/figure6/<run-id>/
  figure6.csv
  raw_seconds.csv
  phase_breakdown.csv
  result.json
plot/figure6a.pdf
plot/figure6b.pdf
```

Validation checks the 2x8-rank launch, one anchor plus four candidates per
panel, 16 trace and marker files per capture, replay completion, ledger
arithmetic, and the submitted trajectory. Both cumulative series must increase
through R4, and FlexEva must remain below Maya in R2--R4. Numeric comparisons
use relative and absolute tolerance `1e-9`.

## Figure 7: component breakdown

Figure 7 uses Megatron GPT 2.7B with sequence length 2048, hidden size 2560,
32 layers, BF16, global batch size 512, and 16 logical ranks. R1--R3 keep
TP1/PP8/DP2; R4 switches to TP2/PP8/DP1. The cumulative mutations are
attention backward, MLP backward, optimizer, and the TP/DP change.

The reported components are full emulation, trace patching, Trace-RAS,
source/RAS update, and configuration refresh. Maya-full, Maya with Trace-RAS,
and FlexEva use the same captured candidate for each round.

Run the CPU check, an optional one-round probe, and the full experiment from
node 0:

```bash
PYTHON_BIN=/path/to/coordinator/python script/run_e3 figure7 self-test

FIGURE7_RUN_ID=figure7-probe-01 FIGURE7_PROBE_ROUND=1 \
  script/run_e3 figure7 probe

FIGURE7_RUN_ID=figure7-production-01 script/run_e3 figure7 run
```

Use a new run ID for each command. Results are written to:

```text
result/e3/generated/figure7/<run-id>/
  manifests/gpt/candidate_manifest.json
  result.json
  breakdown_per_round_wide.csv
  breakdown_cumulative_wide.csv
  README.md
  figure7.{pdf,png}
  formal/{anchor,maya,flexeva}/.../traces/
plot/figure7.pdf
```

Verification checks the 16-rank topology, four rounds, complete trace sets,
selected-trace and patched-trace equivalence, feedback error within 10%,
selective execution in R1--R3, the full R4 configuration refresh, and all
component sums.

Existing results can be checked or re-rendered without a GPU run:

```bash
FIGURE7_RESULT=/path/to/result.json script/run_e3 figure7 verify
FIGURE7_RESULT=/path/to/result.json \
FIGURE7_REPORT_ROOT=/new/report/directory \
  script/run_e3 figure7 report
```

## Figure 8: scale sensitivity

Figure 8 applies the same `attention_backward` mutation to three targets:

| Target | Physical launch | Parallel geometry | Global batch |
| --- | --- | --- | ---: |
| 2.7B / 8 GPU | one node, eight ranks | TP1/PP8/DP1 | 256 |
| 2.7B / 16 GPU | two nodes, eight ranks each | TP1/PP8/DP2 | 512 |
| 18.4B / 16 GPU | two nodes, eight ranks each | TP2/PP8/DP1 | 512 |

Maya-full includes candidate execution, JSONL parsing, trace construction,
replay, and feedback. Maya-trace-RAS compacts the same full trace. FlexEva
measures source analysis, refresh planning, changed-region trace generation,
selected replay, and feedback. This experiment measures trace-processing
cost; it is not a native-training throughput benchmark.

First validate the submitted ledger, then run the three captures from node 0:

```bash
PYTHON_BIN=/path/to/prepared/python script/run_e3 figure8 self-test

export FIGURE8_RUN_ID=figure8-production-01
export FLEXMAYA_MASTER_PORT=29700
export FLEXMAYA_CONTROL_PORT=29800
script/run_e3 figure8 run
```

The launcher collects the local 8-GPU point first, then starts the peer for
both 16-GPU points. It writes:

```text
trace/e3/figure8/<run-id>/<case>/traces/
result/e3/generated/figure8/<run-id>/
  result.json
  summary.csv
  figure8a.csv
  figure8b.csv
  README.md
  figure8.pdf
plot/figure8.pdf
```

Validation checks all three launch geometries, trace and marker coverage,
cross-node transfer, synchronized markers, the fixed source mutation, phase
sums, and JSON/CSV agreement. Event counts may differ from the submitted
ledger by at most 0.1%; refresh ratios by at most 0.1 percentage point. The
default wall-time tolerance is 10% and can be changed explicitly with
`FIGURE8_MAX_TIMING_DRIFT_REL`. Each target has one sample, matching the
submitted experiment.

To verify a completed run:

```bash
FIGURE8_RESULT_ROOT=/path/to/generated/figure8/run \
  script/run_e3 figure8 verify
```
