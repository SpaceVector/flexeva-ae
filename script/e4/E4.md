# E4: Tables 6 and 7

Run E4 once on the coordinator:

```bash
script/run_e4
```

The entry point generates both tables from the current run.

## Table 6

Table 6 runs the ResNet, BERT, and ViT workload-change cases at logical world
size 16 under FakeCUDA. For each case it captures anchor and candidate traces,
analyzes the changed source partitions, measures full replay and selective
refresh, and validates reuse accounting.

## Table 7

Table 7 uses the pinned ASTRA-Sim source and the repository's RAS overlay. The
first run builds ASTRA-Sim below `.deps/`. During the experiment, the driver
generates the GPT and Routed-MoE baselines, runs a full simulation, constructs
the replay cache from that fresh trace, and then measures all six mutation
cases. No replay cache or Table 7 values are supplied as experiment input.

The final layout is:

```text
result/e4/generated/<run-id>/
  table6/
  table7/
  table6.csv
  table7.csv
trace/e4/<run-id>/table6/
```

Set `E4_RUN_ID` to choose the identifier. Existing output is never
overwritten.
