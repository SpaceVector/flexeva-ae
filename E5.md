# Experiment E5: candidate-state memory

E5 reproduces Table 8 and measures the memory cost of keeping multiple
candidate states. The current result is `result/e5/table8.csv`; the archived
submitted-value run remains under `result/e5/submitted/`.

## Method

The experiment builds one anchor with route `(0,1)` and 32 candidates with
distinct ordered top-2 routes. Each candidate has its own source hashes, trace
fingerprint, and lineage edge to the anchor. K=1, 8, and 32 always use the same
ordered candidate prefixes.

The FakeCUDA capture uses 16 logical ranks with EP=8. It records one anchor
and all 32 candidates, with 16 traces and 16 marker files per case. To keep the
raw capture practical, this step uses 2 micro-batches, 2 layers, sequence
length 64, and hidden size 128.

Memory measurement uses the paper state shape:

- 16 logical ranks and EP groups of 8;
- 64 micro-batches and 64 layers;
- sequence length 256 and hidden size 512;
- K=1, 8, and 32 candidates;
- Maya-full, Maya-trace-RAS, and FlexEva;
- three fresh child processes per evaluator/K pair.

The primary metric is the process-lifetime peak RSS delta from `ru_maxrss`.
The retained-RSS diagnostic uses `VmRSS` after GC and `malloc_trim`. Marginal
RSS per candidate is `(median K=32 - median K=1) / 31`.

## Run

Start with the CPU checks:

```bash
PYTHON_BIN=/path/to/python script/run_e5 paper-self-test
```

Run the capture through the server guard:

```bash
export PYTHON_BIN=/path/to/canonical/python
script/e3/server.sh run table8-paper-aligned-01 8 -- script/run_e5 paper
```

The command builds the frozen E5 evaluator, captures 33 route cases, creates
the candidate manifest, runs the 27 RSS probes, measures per-round Maya/FlexEva
speedup, and verifies both result sets.

The result root contains:

```text
capture/capture_manifest.json
collection/candidate_manifest.json
measurement/
  logs/
  measurements.csv
  summary.csv
  result.json
  table8.csv
  table8_retained_diagnostic.csv
  integrity.json
speed/
  logs/
  result.json
  per_round.csv
  samples.csv
  summary.csv
  integrity.json
```

The server guard stores its command, environment, status, and logs in the
guarded run directory.

Verify a completed result with:

```bash
E5_RESULT_ROOT=/path/to/result script/run_e5 paper-verify
```

## Retained result

| Evaluator | K=1 | K=8 | K=32 | Marginal RSS/candidate |
| --- | ---: | ---: | ---: | ---: |
| Maya-full | 0.62 GiB | 2.93 GiB | 10.73 GiB | 334.03 MiB |
| Maya-trace-RAS | 0.27 GiB | 0.46 GiB | 1.14 GiB | 28.92 MiB |
| FlexEva | 0.27 GiB | 0.27 GiB | 0.67 GiB | 13.44 MiB |

At K=32, FlexEva reduces peak RSS by 93.7% relative to Maya-full and 41.0%
relative to Maya-trace-RAS. The 11.28x Maya-full/FlexEva timing ratio reported
with this result covers state construction, not end-to-end evaluation.

Compact measurements and hashes are kept in
`result/e5/paper_aligned_20260901/`. The full traces remain on the experiment
server.

## Checks

Verification requires:

- the configured paper state shape and K values;
- 32 distinct candidates with consistent routes, hashes, and lineage;
- all 33 captures and their trace fingerprints;
- 27 positive RSS measurements from isolated processes;
- the same ordered candidate prefix in every evaluator/K pair;
- K=32 peak RSS greater than K=1 for each evaluator;
- no adjacent median decrease larger than 1 MiB;
- recomputed medians, marginal values, and CSV agreement.

The raw traces use the reduced capture shape described above; the resident
states use the paper shape.
